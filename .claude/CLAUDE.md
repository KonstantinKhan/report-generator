# Project profile

## Делегирование задач субагентам

- При делегировании стадии `Execute` или задачи, связанной с REST API loodsman, субагенту явно передавать в промпте использование `loodsman-rest-api`

## Поиск по REST API loodsman

- `cavecrew-investigator` (и другие агенты без mcp-инструментов) НЕ имеет доступа к `mcp__loodsman__*` - не использовать его для поиска эндпоинтов и DTO Loodsman
- Поиск эндпоинтов/DTO делает либо главный агент напрямую, либо субагент с полным набором инструментов (`general-purpose`)
- В промпте такому субагенту ДОЛЖНО быть: использовать skill `loodsman-rest-api` и вернуть компактный результат - `path`, `method`, параметры, поля DTO (без сырых ответов mcp)
- `cavecrew-investigator` допустим только для поиска по коду проекта (`ast-index`), `wiki-reader` - для контекста по интеграции, не для поиска эндпоинтов
